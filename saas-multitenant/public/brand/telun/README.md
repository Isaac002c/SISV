# Assets oficiais TELUN

Este diretório é o ponto único para os arquivos oficiais isolados da TELUN.
Nenhum símbolo foi redesenhado ou recortado do brand board nesta sprint.

Arquivos esperados, após aprovação da marca:

- `logo-horizontal.svg`
- `symbol.svg`
- `logo-mono-light.svg`
- `logo-mono-dark.svg`
- `favicon.svg`
- fundos institucionais aprovados, se houver

Até esses arquivos existirem, configure URLs aprovadas pelas variáveis
`NEXT_PUBLIC_TELUN_LOGO_URL`, `NEXT_PUBLIC_TELUN_SYMBOL_URL` e
`NEXT_PUBLIC_SISV_FAVICON_URL`. A interface usa fallback tipográfico.
